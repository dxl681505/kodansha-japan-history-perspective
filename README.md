# 讲谈社 · 日本的历史 · 认知档案

> 大和王权是断裂的、新生的。

一个可以直接装进 AI 的**历史分析框架**——用《日本的历史》十册共享的方法看问题。

这不是提示词模板，也不是让模型复述这套书的内容。它注入的是这套通史的**分析路径**：把"连续性"当作需要证明的东西而非前提、按社会结构而非政权更替分期、把日本放进东亚世界、以考古实物与一级文书为准、写被统治者的历史。

区别在于：复述内容得到的是读书笔记；植入分析路径得到的是**处理一个没读过的对象时那套拆解方式**。

## 档案构成

| 部件 | 条数 | 质量约束 |
|------|------|----------|
| 基本立场 | 8 | 每条须在三册以上得到印证，否则注明册次 |
| 操作顺序 | 6 步 | 从"这个说法最早见于什么材料"起到"标出不知道的部分"止 |
| 各册独特切口 | 10 | 每册一个可迁移的观察角度 |
| 学者之间的分歧 | 4 | 含作者自陈少数派、与通行分期不合之处 |
| 框架边界 | 5 | 含中文版总序对丛书局限的直接说明 |

八条基本立场：

1. **"连续性"要证明，不能预设**——任何"自古以来"的说法，都先问它最早见于什么材料、什么年代
2. **分期看社会结构，不看政权更替**——画线的依据是制度与社会的实际变化，不是谁上台谁下台
3. **日本必须在东亚世界里看**——解释内部变动时，先看同期大陆、半岛、海域在发生什么
4. **实物证据优先**——判断一个说法能不能站住，先看它有没有出土物或原始文书支撑
5. **"常识"往往是很晚才形成的**——把"通说"当作需要交代来历的对象
6. **写被统治者的历史**——一个时代的样貌不能只由它的统治者来代表
7. **史料批判：先问是谁写的**——一条记载出现在史书里，不等于它是当时的事实
8. **承认不知道**——结论和不确定性要一起说出

## 蒸馏方法

采用「仓颉 · 认知植入术」的四条铁律：

1. 没形成故事的信念不进
2. 没反思的决策不进
3. 不写 Step 1 / 2 / 3 这类推理步骤
4. 全部第一人称

第 3 条是关键。写推理步骤等于把模型本来就会的东西重新教一遍，占位置还没用。真正有价值的是那些**模型不可能从通用训练数据里知道的东西**——具体的人、具体的事、具体的失败。

**多作者丛书的特殊处理**：十册单人独著，不存在"讲谈社的立场"这种东西，只有十位学者各自的处理。因此产出的不是"某人的思维"，而是**这套书共享的编辑方针 + 各册各自的问题意识**。凡是标为"丛书共性"的判断，都在三册以上得到印证；单册主张注明册次。

## 素材来源

十册中文版的**框架性章节**：总序、推荐序、前言、序章、终章/结束语/后记，以及部分正文补读。

约 170 万字全文无法逐字处理，提取策略是抓取最能暴露分期逻辑与论证方式的位置，再对框架章节严重不足的册补读正文。

**十册清单**：

| 册 | 时代 |
|---|---|
| 01 | 王权的诞生：弥生时代—古坟时代 |
| 02 | 从大王到天皇：古坟时代—飞鸟时代 |
| 03 | 律令国家的转变：奈良时代—平安时代前期 |
| 04 | 武士的成长与院政：平安时代后期 |
| 05 | 源赖朝与幕府初创：镰仓时代 |
| 06 | 《太平记》的时代：南北朝时代—室町时代 |
| 07 | 织丰政权与江户幕府：战国时代 |
| 08 | 天下泰平：江户时代前期 |
| 09 | 开国与幕末变革：江户时代后期 |
| 10 | 维新的构想与开展：明治时代 |

**中文版总序是重要材料**：王勇撰「横看成岭侧成峰——日本人书写的日本历史」，对这套书的定位与局限有直接说明——长处是作者作为"当事人"而非"旁观者"书写，局限是「这套丛书呈现的基本上是'和'之一脉，甚至对国外同行的研究成果也有所忽略」。档案把这段原样保留。

**关于原始文本**：`references/source-text/` 下的 epub 解包全文受版权限制，未随仓库分发。档案中的引用以该解包文本为准，如需核对请自行获取书目并按同法解包，行号可能因版本而异。

## 质量自检

全部引文经脚本化批量溯源校验——对 `SKILL.md` 与 `references/` 中所有「」引文，做"去引号/去省略号后子串匹配解包源文本"的核对。两个核心文件共 131 条引文（与姊妹仓库《兴亡的世界史》合计），全部可在源文本中定位。

校验中查出并修正了 18 处「概括表述被误加引号」。典型的日本史案例：「歧见迭出，极为混乱」查无此句且夸大，原文是「《古事记》和《日本书纪》的记述虽稍有分歧」。另在 02/03 档案中写明引用规范：`「」` 既用于逐字原文引用，也用于**指称**被批判的通说、他人学说或概念名。

## 已知局限

- **十册是选本**，日文原版共二十六卷。选题侧重政治社会史，文化、艺术、经济史的覆盖不均衡。
- **普及读物**，面向普通读者。重大争点会交代，但不做完整学术综述。
- **地域覆盖不均**：北海道（阿伊努）、冲绳的叙述主要出现在第 9 册，其他册着墨有限。
- **终止于明治**：第 10 册止于 1889 年宪法颁布。**近现代（20 世纪）不在覆盖范围内**。
- **第 04、05、07、10 册的框架性章节提取不足**，结论主要依赖补读正文，可靠性略低于其他册（已在 `01-sources.md` 标注）。

## 姊妹档案

同一方法产出的另一套：《讲谈社·兴亡的世界史》分析框架——[kodansha-world-history-perspective](https://github.com/dxl681505/kodansha-world-history-perspective)。

两套书的性格不同，可以对照使用：世界史是**横切**（每卷锁一个文明/帝国单位），日本史是**纵贯**（按时代接续通史）。
